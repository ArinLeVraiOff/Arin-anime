# StreamFree

Petit site de streaming gratuit en HTML, CSS et JavaScript.

## Lancer le site localement

Depuis le dossier du projet :

```bash
cd /workspaces/Arin-anime
python3 -m http.server 8000
```

Ensuite ouvrez :

```text
http://localhost:8000
```

## Contenu

- page d’accueil moderne
- catalogue avec filtres
- recherche par titre
- lecteur vidéo intégré
- design sombre inspiré des plateformes de streaming
